# mach.lang.target.extension.x64

## val SSSE3

```mach
pub val SSSE3: u64 = 0x1
```

the x86_64 extension vocabulary over the SSE2 baseline. a row is a name the
manifest, `$mach.build.extensions.<name>`, `#[extensions(...)]` and the
inline-asm `requires:` rows all spell; a row nothing encodes against yet is
still a declared, probed requirement

## val NAMES

```mach
pub val NAMES: [NAME_COUNT]extension.Extension = [NAME_COUNT]extension.Extension;
```

sse41 brings ssse3 (sse3 is not modelled, so the chain stops there), sse42
brings sse41, avx brings sse42, avx2, fma and f16c bring avx, and every
avx512 set brings avx512f, which brings avx2

## val LEVEL_V2

```mach
pub val LEVEL_V2: u64 = SSSE3 | SSE41 | SSE42 | POPCNT | CX16
```

the published x86-64 microarchitecture levels as manifest spellings. each
level lists its own members over the v1 baseline (sse2, cmpxchg8b and
lahf-sahf are the baseline and are not rows) and includes every lower level;
closing the selection over `implies` adds nothing a level does not already
name. doc/language/manifest.md carries the same table and a test holds the
two together
