# mach.report

how running work reports itself: the status a phase ends with, the progress readout a
command renders, and the results of a test run

| Module | |
| :--- | :--- |
| [`phase`](phase.md) | the status a phase ends with: accepted, rejected through diagnostics, or failed |
| [`readout`](readout.md) | the progress events a command reports, and the timed phase rows of a build unit |
| [`testrun`](testrun.md) | collected tests, the result of each run and the tally over a run's results |
