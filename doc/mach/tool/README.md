# mach.tool

whole-source tools built on the front end: the formatter, the migrator and the
documentation generator

| Module | |
| :--- | :--- |
| [`doc`](doc.md) | the documentation generator: a project's reference, written as markdown pages into the one directory the generator owns, `<dir>/<project id>/` |
| [`format`](format.md) | the formatter: one canonical layout of a source file, from its tokens and its parsed tree |
| [`migrate`](migrate.md) | a project written for the previous major, rewritten into this one's spelling, which `mach migrate` applies |

| Directory | |
| :--- | :--- |
